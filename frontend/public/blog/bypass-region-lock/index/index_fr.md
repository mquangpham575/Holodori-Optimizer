Bonjour les HoloDreamers ! Actuellement, **Hololive Dreams** implémente une restriction d'IP régionale (Region Lock). Cela rend le téléchargement et la connexion au jeu difficiles depuis les pays non pris en charge (comme le Vietnam).

Vous trouverez ci-dessous le guide étape par étape pour **Android** et **Windows (PC)** pour vous aider à obtenir la meilleure expérience de jeu.


# PARTIE 1 : ANDROID

## 1. Comment télécharger sur Android
Étant donné que le téléchargement du jeu sur le Google Play Store est également bloqué par région, vous devez changer la région de votre boutique à l'aide d'un VPN :

- **Étape 1** : Installez l'application **VPN.lat** depuis le Google Play Store ou d'autres sources officielles.
- **Étape 2** : Ouvrez l'application. L'écran principal de VPN.lat est affiché ci-dessous. Sélectionnez une région prise en charge (comme les États-Unis, le Vietnam, etc., selon l'endroit où vous souhaitez vous connecter).
  
  ![Interface principale de VPN.lat](/blog/bypass-region-lock/imgs/android_vpn_ui.png)

- **Étape 3** : Choisissez l'un des serveurs disponibles dans cette région pour vous connecter.
  
  ![Liste des serveurs VPN.lat](/blog/bypass-region-lock/imgs/android_vpn_list.png)

- **Étape 4** : Une fois le VPN connecté, accédez à **Paramètres de l'appareil -> Applications -> Google Play Store -> Stockage -> Vider le cache**.
- **Étape 5** : Rouvrez le Google Play Store, recherchez **Hololive Dreams** et téléchargez-le.


## 2. Comment se connecter sur Android
- Une fois le jeu installé, ouvrez le jeu et essayez de vous connecter.
- Vous pouvez garder VPN.lat actif pendant que vous jouez, ou vous pouvez essayer de **désactiver le VPN** après le chargement du jeu pour voir s'il fonctionne sans lui.
- Si vous rencontrez une erreur de connexion comme celle ci-dessous :
  
  ![Erreur de connexion de données Android](/blog/bypass-region-lock/imgs/android_game_error.png)
  
  Veuillez réactiver **VPN.lat** et redémarrer le jeu pour résoudre le problème.

**Remarque :** L'auteur a testé et constaté que les serveurs **US15** et **VN1, VN2, VN3** dans VPN.lat fonctionnent le mieux.


# PARTIE 2 : WINDOWS (PC)

## 1. Comment télécharger sur Windows
- Contrairement à Android, sur PC, vous pouvez télécharger le jeu directement via [Steam](https://store.steampowered.com/).


## 2. Comment se connecter sur Windows
Si vous rencontrez une erreur de connexion de données (Failed to retrieve data) sur PC comme indiqué ci-dessous :
  
![Erreur de connexion de données PC](/blog/bypass-region-lock/imgs/pc_game_error.png)
  
Veuillez connecter ou reconnecter le client **SoftEther VPN Client** en suivant les étapes suivantes pour contourner la restriction de connexion :

- **Étape 1** : Visitez le [centre de téléchargement SoftEther](https://www.softether-download.com/) et téléchargez le dernier programme d'installation pour Windows.
- **Étape 2** : Lancez le programme d'installation et sélectionnez l'option **SoftEther VPN Client**.
- **Étape 3** : Cliquez sur **Suivant** jusqu'à la fin. Acceptez de créer une carte réseau virtuelle lorsque vous y êtes invité.
  
  ![Configuration de SoftEther VPN](/blog/bypass-region-lock/imgs/image.png)

- **Étape 4** : Double-cliquez sur **VPN Gate Public VPN Relay Servers** dans la fenêtre du client SoftEther VPN.
- **Étape 5** : Sélectionnez un serveur dans une région prise en charge (par exemple, le Japon ou les États-Unis). Vous pouvez cliquer sur **Actualiser la liste** pour renouveler la liste des serveurs.
  
  ![Serveurs de relais publics VPN Gate](/blog/bypass-region-lock/imgs/image-1.png)

- **Étape 6** : Choisissez le protocole de connexion (recommandé **TCP**) et cliquez sur **Connecter**. Once the status says **Connecté**, lancez le jeu et jouez normalement !

**Remarque :** Sur PC, toutes les régions comme **US** (États-Unis), **JP** (Japon) ou **VN** (Vietnam) peuvent être utilisées pour se connecter au jeu tant que la connexion est établie avec succès.

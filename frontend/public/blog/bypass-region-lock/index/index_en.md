Hello HoloDreamers! Currently, **Hololive Dreams** implements a regional IP restriction (Region Lock). This makes downloading and logging into the game difficult from unsupported countries (such as Vietnam).

Below is the step-by-step guide for both **Android** and **Windows (PC)** to help you get the best gaming experience.


# PART 1: ANDROID

## 1. How to Download on Android
Since the game download on Google Play Store is also region-locked, you need to change your store region using a VPN:

- **Step 1**: Install the **VPN.lat** app from Google Play Store or other official sources.
- **Step 2**: Open the app. The main screen of VPN.lat is shown below. Select a supported region (like United States, Vietnam, etc. depending on where you want to connect).
  
  ![VPN.lat Main UI](/blog/bypass-region-lock/imgs/android_vpn_ui.png)

- **Step 3**: Choose one of the available servers in that region to connect.
  
  ![VPN.lat Server List](/blog/bypass-region-lock/imgs/android_vpn_list.png)

- **Step 4**: Once the VPN is connected, go to **Device Settings -> Apps -> Google Play Store -> Storage -> Clear Cache**.
- **Step 5**: Reopen Google Play Store, search for **Hololive Dreams**, and download it.


## 2. How to Log In on Android
- Once the game is installed, open the game and try logging in.
- You can keep VPN.lat active while playing, or you can try **turning the VPN off** after the game loads to see if it works without it.
- If you encounter a connection error like the one below:
  
  ![Android Data Connection Error](/blog/bypass-region-lock/imgs/android_game_error.png)
  
  Please turn **VPN.lat** back on and restart the game to fix it.

**Note:** The author has tested and found that **US15** and **VN1, VN2, VN3** servers in VPN.lat work best.


# PART 2: WINDOWS (PC)

## 1. How to Download on Windows
- Unlike Android, on PC, you can download the game directly through [Steam](https://store.steampowered.com/).


## 2. How to Log In on Windows
If you encounter a data connection error (Failed to retrieve data) on PC as shown below:
  
![PC Data Connection Error](/blog/bypass-region-lock/imgs/pc_game_error.png)
  
Please connect or reconnect **SoftEther VPN Client** using the following steps to bypass the login restriction:

- **Step 1**: Visit the [SoftEther Download Center](https://www.softether-download.com/) and download the latest installer for Windows.
- **Step 2**: Run the installer, and select the **SoftEther VPN Client** option.
- **Step 3**: Click **Next** until completion. Agree to create a Virtual Network Adapter when prompted.
  
  ![SoftEther VPN Setup](/blog/bypass-region-lock/imgs/image.png)

- **Step 4**: Double-click **VPN Gate Public VPN Relay Servers** in the SoftEther VPN Client window.
- **Step 5**: Select a server in a supported region (e.g., Japan or United States). You can click **Refresh List** to renew the server list.
  
  ![VPN Gate Public Relay Servers](/blog/bypass-region-lock/imgs/image-1.png)

- **Step 6**: Choose the connection protocol (recommend **TCP**) and click **Connect**. Once the status says **Connected**, launch the game and play normally!

**Note:** On PC, all regions like **US** (United States), **JP** (Japan), or **VN** (Vietnam) can be used to log into the game as long as you connect successfully.

Hallo HoloDreamers! Derzeit implementiert **Hololive Dreams** eine regionale IP-Beschränkung (Region-Lock). Dies erschwert das Herunterladen und Einloggen in das Spiel aus nicht unterstützten Ländern (wie Vietnam).

Nachfolgend finden Sie eine Schritt-für-Schritt-Anleitung für **Android** und **Windows (PC)**, um Ihnen das beste Spielerlebnis zu ermöglichen.


# TEIL 1: ANDROID

## 1. Herunterladen auf Android
Da der Spieledownload im Google Play Store ebenfalls regional gesperrt ist, müssen Sie Ihre Store-Region mithilfe eines VPNs ändern:

- **Schritt 1**: Installieren Sie die App **VPN.lat** aus dem Google Play Store oder anderen offiziellen Quellen.
- **Schritt 2**: Öffnen Sie die App. Der Hauptbildschirm von VPN.lat ist unten dargestellt. Wählen Sie eine unterstützte Region aus (z. B. USA, Vietnam usw., je nachdem, wohin Sie sich verbinden möchten).
  
  ![VPN.lat Haupt-UI](/blog/bypass-region-lock/imgs/android_vpn_ui.png)

- **Schritt 3**: Wählen Sie einen der verfügbaren Server in dieser Region aus, um eine Verbindung herzustellen.
  
  ![VPN.lat Serverliste](/blog/bypass-region-lock/imgs/android_vpn_list.png)

- **Schritt 4**: Sobald die VPN-Verbindung hergestellt ist, gehen Sie zu **Geräteeinstellungen -> Apps -> Google Play Store -> Speicher -> Cache leeren**.
- **Schritt 5**: Öffnen Sie den Google Play Store erneut, suchen Sie nach **Hololive Dreams** und laden Sie es herunter.


## 2. Einloggen auf Android
- Sobald das Spiel installiert ist, öffnen Sie es und versuchen Sie, sich einzuloggen.
- Sie können VPN.lat während des Spielens aktiv lassen oder versuchen, **das VPN auszuschalten**, nachdem das Spiel geladen wurde, um zu sehen, ob es auch ohne funktioniert.
- Wenn Sie auf einen Verbindungsfehler wie den folgenden stoßen:
  
  ![Android-Datenverbindungsfehler](/blog/bypass-region-lock/imgs/android_game_error.png)
  
  Bitte schalten Sie **VPN.lat** wieder ein und starten Sie das Spiel neu, um das Problem zu beheben.

**Hinweis:** Der Autor hat festgestellt, dass die Server **US15** und **VN1, VN2, VN3** in VPN.lat am besten funktionieren.


# TEIL 2: WINDOWS (PC)

## 1. Herunterladen auf Windows
- Im Gegensatz zu Android können Sie das Spiel auf dem PC direkt über [Steam](https://store.steampowered.com/).


## 2. Einloggen auf Windows
Wenn Sie auf dem PC einen Datenverbindungsfehler (Failed to retrieve data) wie unten dargestellt erhalten:
  
![PC-Datenverbindungsfehler](/blog/bypass-region-lock/imgs/pc_game_error.png)
  
Bitte verbinden oder verbinden Sie den **SoftEther VPN Client** mithilfe der folgenden Schritte neu, um die Login-Beschränkung zu umgehen:

- **Schritt 1**: Besuchen Sie das [SoftEther Download Center](https://www.softether-download.com/) und laden Sie das neueste Installationsprogramm für Windows.
- **Schritt 2**: Führen Sie das Installationsprogramm aus und wählen Sie die Option **SoftEther VPN Client**.
- **Schritt 3**: Klicken Sie auf **Weiter** bis zum Abschluss. Stimmen Sie der Erstellung eines virtuellen Netzwerkadapters zu, wenn Sie dazu aufgefordert werden.
  
  ![SoftEther VPN-Einrichtung](/blog/bypass-region-lock/imgs/image.png)

- **Schritt 4**: Doppelklicken Sie im SoftEther VPN Client-Fenster auf **VPN Gate Public VPN Relay Servers**.
- **Schritt 5**: Wählen Sie einen Server in einer unterstützten Region aus (z. B. Japan oder USA). Sie können auf **Liste aktualisieren** klicken, um die Serverliste zu erneuern.
  
  ![VPN Gate Öffentliche Relay-Server](/blog/bypass-region-lock/imgs/image-1.png)

- **Schritt 6**: Wählen Sie das Verbindungsprotokoll (empfohlen **TCP**) und klicken Sie auf **Verbinden**. Sobald der Status **Verbunden** lautet, starten Sie das Spiel und spielen Sie normal!

**Hinweis:** Auf dem PC können alle Regionen wie **US** (USA), **JP** (Japan) oder **VN** (Vietnam) zum Einloggen in das Spiel verwendet werden, solange Sie erfolgreich eine Verbindung herstellen.
